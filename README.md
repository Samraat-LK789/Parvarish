# Parvarish

Parvarish is a premium real-estate landing experience designed to showcase collectible architecture and flagship properties. The site focuses on a clean, editorial layout with immersive hero visuals, curated project highlights, and a direct contact section.

## Highlights

- Immersive hero section with a focused feature preview
- Curated projects grid with expanded view
- About and contact sections tailored for high-end branding
- Responsive navigation with a simple mobile menu

- Home (hero)
